# AI Usage

Deepseek is the most heavily used AI for my project. It was used in the generation of several files and classes such as the Storage, DateTimeParser
and AfterParse classes. It helped
- make the logic for parsing input
- designed a way to handle multiple date time formats
- design persistent storage
- make my project more OOP style
- explain errors or exceptions that I don't know
- help me with javafx and make a more functional GUI

Most of its code generated works fine. The challenges come when:
- code generated doesn't fit into my existing code design
- code generated has things that I don't understand

It saved me a lot of time as sometimes I don't even know where to begin, such as for the increment of saving the tasks
to the local hard disk, and loading them. Probably saves me about 6 hours each week. <br><br>
I noticed it uses things that are not covered in the javafx tutorial when it helps me with the GUI. Then, when I integrate it into my code, it results
in some error or undesired outcome and I have to figure out what's wrong. It does things a bit differently from the tutorial in SE EDU. But
I didn't upload all my relevant code for it too, so maybe that's why.
